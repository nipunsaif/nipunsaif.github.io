Selected Research Projects

My research lies at the intersection of Artificial Intelligence and the Internet of Things. I specialize in Deep Learning, with a specific focus on Computer Vision, Natural Language Processing, and Generative AI. Key reports are highlighted below.

// Machine Learning  ·  University Project  ·  2025
CareerMAS: A Multi-Agent LLM Framework for Career Guidance and Job Placement in Bangladesh
Saif Mohammed, Humayra Rahman Nipa, Ankita Kundu, Sabab Ashfak Fahim
A multi-agent framework integrating web-scraped data and ML-based salary prediction to provide personalized career recommendations. Using fine-tuned LLMs, it converts unstructured job listings into actionable insights to align job seekers with market demands in Bangladesh.
Report / Code
// Junior Design Project  ·  University Project  ·  2025
DiabetIQ: An Intelligent Diabetes Management Application with an Integrated LLM-Augmented Chatbot and Machine Learning-Driven Early Risk Prediction
Saif Mohammed, Nazibul Islam Nabil, Humayra Rahman Nipa, Umme Suraia Haque Setu
A Flutter-based health framework combining an LLM-augmented RAG chatbot for verifiable medical advice with ML-based early risk prediction. The system analyzes user health data to predict hypo- and hyperglycemia risks, enabling proactive diabetes care.
Report / Code
// Artificial Intelligence  ·  University Project  ·  2025
ClueChain: A Bayesian Network-Based Mystery Solver Application
Saif Mohammed, Humayra Rahman Nipa, Mainul Kaysar, Jannatul Islam, Saif Uz Zaman
An interactive application that applies Bayesian inference to fictional mystery scenarios. Users input clues and evidence, and the system calculates the probabilities of different suspects, offering a data-driven approach to deduction.
Report / Code
// Deep Learning  ·  University Project  ·  2025
AI-Powered Competitive Programming Code Generation Tool Leveraging Large Language Models
Saif Mohammed, Shawal Kabir Chy., Sadia Ibnat Isamoni, Humayra Rahman Nipa
An iterative pipeline using Code LLaMA and Mistral-7B to generate, verify, and explain algorithmic solutions. By combining self-reflection with execution-based debugging, the system improves solution accuracy and provides pedagogical support for competitive programming.
Report / Code
// Digital Logic Design  ·  University Project  ·  2023
7 Segment LED Display Project: Combinational and Sequential Logic Circuit Design to Display "IUBFALL"
Saif Mohammed, Al Zamee, Humayra Rahman Nipa, Umme Suraia Haque Setu
A hardware implementation utilizing a 4:1 Multiplexer and seven-segment display to visualize the text sequence "IUBFALL". This project demonstrates cost-effective and rapid prototyping of interactive displays using fundamental logic circuit design.
